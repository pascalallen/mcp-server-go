This is a knowledge base entry. Each entry is a Markdown file in the
knowledge base directory (`data/kb` by default, configurable with the
`KB_DIR` environment variable) with YAML front matter for the title and
tags. The filename is the entry's slug — this file is `kb://welcome`.

Use the `kb_add`, `kb_update`, and `kb_delete` tools to manage entries,
`kb_search` and `kb_list` to find them, and read any entry as an MCP
resource at `kb://{slug}`.
